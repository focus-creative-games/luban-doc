# 表头含义与常见错误

## 表头行一览

| 你看到的 | 意思 | 能不能改 |
|----------|------|----------|
| `##` / `##var` | 字段名行 | 列名一般由程序定；加列要找程序 |
| `##type` | 类型行 | **不要**改成中文或「看起来像」的字 |
| `##group` | 导出分组 | 按项目规范填 `c` / `s`；不确定问程序 |
| `##` / `##comment` | 注释行 | 可写中文说明；整行不导出 |
| 数据行 | 真正进包的内容 | 你的主战场 |

完整小例子：

| ##var | id | name | on_sale | #内部说明 |
|---|---|---|---|---|
| ##type | int | string | bool | |
| ##group | | c,s | c | |
| ## | 道具ID | 名称 | 是否上架 | 不进包 |
| | 1001 | 金币 | 是 | 随便写 |
| ## | 1002 | 草稿 | 否 | 本行整行不导出 |

## 注释列 vs 注释行

| 形态 | 怎么识别 | 结果 |
|------|----------|------|
| 注释列 | 字段名为空，或以 `#` 开头（如 `#备注`） | 这列填了也不进游戏 |
| 注释行 | 该行**第一格**以 `##` 开头 | 整行忽略 |

## 常见类型怎么填

| ##type 里写的 | 你可以填 | 注意 |
|---------------|----------|------|
| int / float | 数字；多数可留空当 0 | 不要填「一百」 |
| bool | `是`/`否`、`true`/`false`、`0`/`1` | |
| string | 任意文字；空格子一般是空串 | 真要「空」有时要按程序说明填 `""` |
| 枚举名（如 Quality） | 枚举英文名、中文别名、或数字 | 别名以程序提供的为准，如 `白` |
| datetime | 日期时间 | 一般**不要留空** |
| 带 `?` 的类型（如 `int?`） | 可留空或填 `null` 表示没有 | 与「填 0」不是一回事 |

枚举示例：

| ##var | id | quality |
|---|---|---|
| ##type | int | Quality |
| | 1 | WHITE |
| | 2 | 白 |
| | 3 | 1 |

## 常见错误对照

| 现象 | 可能原因 | 怎么办 |
|------|----------|--------|
| 整表没导出 | Sheet 左上角不是 `##`；或表未登记 | 看 A1；问程序是否在 `__tables__` 里 |
| 某列客户端没有 | `##group` 写成了 `s` | 改成 `c` 或 `c,s` / 留空（以规范为准） |
| 类型报错 | 文字进了 int；枚举名拼错 | 对照 `##type` 与枚举名单 |
| 引用 / id 报错 | 填了不存在的道具 id 等 | 先在目标表确认 id 存在 |
| 填了备注却进游戏 | 字段名没加 `#`，被当成正式列 | 备注列名改成 `#xxx` 或空 |
| 某行怎么改都不生效 | 该行第一格是 `##` 注释行 | 去掉行首 `##` |
