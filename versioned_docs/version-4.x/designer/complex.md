# 复杂结构怎么填

坐标、消耗、奖励列表、技能效果（多态）等，表头会比「一列一个数」更复杂。按程序给的**样表**填；下面用常见形态说明读法。

## 合并单元格 = 一个小结构

一个字段（如「消耗」）占多列时，程序会把这几列**合并**，表示同属一个字段。请按从左到右的子字段填，**不要拆开合并区域**，也不要在中间插入无关列。

示意（`cost` 占两列：道具 id + 数量）：

<table>
  <thead>
    <tr>
      <th>##var</th>
      <th>id</th>
      <th colspan="2">cost</th>
      <th>name</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>##var</td>
      <td></td>
      <td>id</td>
      <td>count</td>
      <td></td>
    </tr>
    <tr>
      <td>##type</td>
      <td>int</td>
      <td>int</td>
      <td>int</td>
      <td>string</td>
    </tr>
    <tr>
      <td></td>
      <td>1</td>
      <td>1001</td>
      <td>5</td>
      <td>兑换A</td>
    </tr>
  </tbody>
</table>

读法：第 1 行，`cost` 横跨两列；下一行子表头是 `id` / `count`。  
含义：消耗 5 个 id=1001 的道具。

## 列表：一排多个 / 多行多条

**同一行里多个格子** = 列表的多个元素（按程序表头顺序填）。

**字段名带 `*`**（或程序说明「多行列表」）时：下面多行属于同一条主记录的列表项，主键列常留空表示「延续上一行」。以样表为准，不要自行合并或拆行。

简单一格写法（若表头带了分隔说明）：

| ##var | id | item_ids |
|---|---|---|
| ##type | int | list,int |
| | 1 | 1001,1002,1003 |

具体分隔符是逗号、`|` 还是别的，看该列表头或 `#sep` 说明。

## 多态：先写类型名，再写参数

技能条件、效果、形状等字段，往往先标明**哪一种**，再填这种需要的参数。

| 你填的 | 意思 |
|--------|------|
| 类型名 / 中文别名 | 必须来自程序提供的名单，如 `Circle`、`矩形`、`Heal` |
| 后面的数字/字段 | 该类型的参数；无关列留空 |

分列示意：

<table>
  <thead>
    <tr>
      <th>##var</th>
      <th>id</th>
      <th colspan="4">shape</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>##var</td>
      <td></td>
      <td>$type</td>
      <td>radius</td>
      <td>width</td>
      <td>height</td>
    </tr>
    <tr>
      <td></td>
      <td>1</td>
      <td>Circle</td>
      <td>1.5</td>
      <td></td>
      <td></td>
    </tr>
    <tr>
      <td></td>
      <td>2</td>
      <td>矩形</td>
      <td></td>
      <td>2</td>
      <td>3</td>
    </tr>
  </tbody>
</table>

一格紧凑写法（若程序开了）：

| 单元格示例 | 含义 |
|------------|------|
| `Circle,1.5` | 圆，半径 1.5 |
| `{Rect,2,3}` | 矩形，宽 2 高 3 |

注意：若程序说该字段**不能为空**，就不要填 `null` 或整段留空。

## 一个单元格里的短格式

有的列用 `1,2,3` 或 `{1,2,3}`。以表头上的 `sep` / `format` 或样例行为准，不要混用另一张表的写法。

## 填复杂列时的习惯

1. 先看样表同一列已有的合法行，复制再改。
2. 合并区域只改数值，不改表头结构。
3. 多态类型名从程序名单复制，避免手打拼错。
4. 生成报错会带表名/行列，把完整报错发给程序最快。
