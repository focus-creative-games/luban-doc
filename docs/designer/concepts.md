# 你需要懂的最小概念

给策划：不必理解代码生成细节。记住下面几条，就能和程序对上话、少踩坑。

## 三件事

1. **表要先登记**：程序在 `__tables__`（或 XML）里登记后，你的 Excel 才会被导出。只在自己电脑新建 xlsx **不会**自动进包。
2. **表头有规矩**：左上角附近带 `##` 的是标题区，不是普通数据。A1 不是 `##` 开头的 sheet，工具会当它不存在。
3. **客户端 / 服务器可能看到不同列**：`##group` 里的 `c` / `s` 表示这列给谁；填错会导致「客户端缺字段」或「敏感数值泄漏到客户端」。

## 一张表示意

| ##var | id | name | price | drop_weight | #备注 |
|---|---|---|---|---|---|
| ##type | int | string | int | int | |
| ##group | | c,s | c | s | |
| ## | 道具ID | 名称 | 价格 | 掉落权重 | 策划备注 |
| | 1001 | 金币 | 0 | 100 | 基础货币 |

| 你看到的 | 实际意思 |
|----------|----------|
| `##var` 行 | 字段英文名（程序用） |
| `##type` 行 | 类型（由程序定，不要乱改） |
| `##group` 行 | `c`=客户端，`s`=服务器 |
| `#备注` 列 | 注释列，**不进游戏** |
| 数据行 | 真正导出的内容 |

## 和程序怎么分工

| 你 | 程序 |
|----|------|
| 按表头填数、改数值 | 定字段类型、主键、哪些列给客户端 |
| 按样表填嵌套 / 多态 | 定义结构、子类型名字与别名 |
| 提需求「加一列 xxx」 | 改 Schema，再告诉你新列写在哪、怎么填 |
| 生成失败时贴完整报错 | 根据行列定位修类型或引用 |

## 不要自己做的事

- 不要改 `##type` 里的类型名（例如把 `int` 改成「整数」）。
- 不要拆开程序合并好的表头单元格再乱拖列。
- 不要假设「文件在 Datas 目录里就会导出」——必须先登记。
