# 与程序协作检查清单

提交或提测前快速自检。勾选越全，返工越少。

## 表与表头

- [ ] 表已在配置工程中登记（不是只有自己本地 xlsx）
- [ ] Sheet 标题区以 `##` 开头（A1 常见为 `##` / `##var`）
- [ ] 没有在 `##type` 行把类型改成中文或自创名
- [ ] 注释列字段名为 `#xxx` 或空，没有误当成数据列
- [ ] 草稿行用行首 `##` 注释，或确认不会进正式导出

## 数值与引用

- [ ] 主键不重复（map 表）
- [ ] 引用到的道具 / 关卡 / 掉落 id 在目标表真实存在
- [ ] 枚举填的是程序提供的名字或别名（如 `白` / `WHITE`）
- [ ] 不允许为空的列没有留空；可空列的「没有」按约定留空或 `null`
- [ ] datetime 没有随便留空

## 客户端 / 服务器

- [ ] 仅服务器用的权重、公式参数等已标 `s`（或按项目规范）
- [ ] 显示用字段没有误标成仅 `s` 导致客户端缺失
- [ ] 不确定的 group 已问过程序，而不是一律留空

## 复杂结构

- [ ] 合并单元格区域没有被拆开或列错位
- [ ] 列表分隔符与样表一致
- [ ] 多态类型名来自程序名单，没有写成抽象基类名
- [ ] 多行列表的续行主键留空方式与样表一致

## 生成失败时怎么反馈

发给程序时尽量带齐：

1. **完整报错原文**（不要只截最后一行）
2. **表名 / 文件名 / Sheet 名**
3. **出问题的行 id 或大致行列**
4. 你改过的字段截图或说明

Luban 报错通常能指到单元格级问题；信息越全，定位越快。
