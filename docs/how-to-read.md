# 文档怎么读

按角色选一条路径即可，不必从上读到下。

1. [心智模型](./mental-model) — 建立四步图
2. [快速上手](./guide/install) — 30 分钟跑通生成与加载
3. [术语表](./concepts/glossary) + [luban.conf](./concepts/luban-conf) — 统一说法
4. 按需深入：
   - 表怎么填 → [Excel 基础](./excel/basics)
   - 结构怎么定 → [Excel Schema](./schema/excel-schema)
   - 命令与目标 → [常用命令行](./runtime/cli-common)
   - 校验 / 分端 / 本地化 → [质量与发布](./quality/validators)
5. 二次开发 → [扩展 Luban](./extend/overview)
6. 查参数 → [参考手册](./reference/cli)

## 页面写法约定

每篇正文尽量按同一结构：

1. 一句话结论  
2. 最小例子  
3. 规则（条目化）  
4. 常见坑  
5. 相关链接  

**参考手册**章节是查表用的，不讲故事；概念与上手章节才讲「为什么」。

- 本站默认文档为 **Luban 4.x（current）**。
- 顶部版本下拉里的 **1.x / 3.x（classic）** 为历史文档，**本轮未改写**，仅供旧项目查阅。
